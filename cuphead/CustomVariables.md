# Custom Variables

Custom variables are fields that can be added to a Livesplit layout to display additional information.
The Cuphead autosplitter currently offers two:

- **Level Time**: displays the current In-Game Time for a level.
- **Star Skip Counter**: displays how many Star Skips have happened during the course of the run.

# How to add Custom Variables

- Right click on the Livesplit window and select **Edit Layout**
- Click on the + sign and add a new **Text** component (under Information)
- Double click on the newly added Text component to open its settings in a new window
- In the newly opened window:
  - Tick the **Custom Variable** checkbox
  - Under **Right Text**, set the **Custom Variable Name** to the name of the value you'd like to track (for example, **Level Time** for the level time, and **Star Skip Counter** for the star skip counter. Refer to the list of custom variables above for the name you need)
  - Under **Left Text**, set the **Text** field to a name of your choice. This will visibly appear in your layout and it basically corresponds to what you want to label the value. It is recommended to name this the same as the text you've inputted in the previous step
  - Click OK in the Layout Settings window
- Click OK in the Layout Editor window

If everything was done correctly, you should now have the custom variable added to your layout.
